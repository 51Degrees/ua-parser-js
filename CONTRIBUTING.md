# Contributing

Contributions are welcome. This repository has branched from
[UAParser.js](https://github.com/faisalman/ua-parser-js), so changes to it are
proposed here, not to UAParser.js. The
[51Degrees contributing guide](https://github.com/51Degrees/.github/blob/main/CONTRIBUTING.md)
explains how to propose one, which is to take a branch from `rc` and open the
pull request against `rc`.

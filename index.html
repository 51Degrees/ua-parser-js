Device Detection for JavaScript

51Degrees UAParser

Know which device, operating system, and browser each visitor is using. UAParser is a small JavaScript package that reads the User-Agent and User-Agent Client Hints, then gets the answer from 51Degrees Device Detection in the 51Degrees cloud service.

Use it in the browser to detect the current visitor, or in Node.js with the HTTP headers you pass in. A free Resource Key returns the device type. A paid plan adds the browser, the operating system, and the hardware vendor and model, iPhones and iPads included. This page's key is on a paid plan, so the playground shows them all.

Less is more

Extensive device data

UAParser gets its answers from the 51Degrees cloud service, which offers over 200 device properties, such as the platform, browser, layout engine, CPU, and vendor.

Small library footprint

The minified library is about 16 KB, so it adds very little to your page.

Open source with a freemium model

UAParser is open source and free to use with a limited set of properties. If you need more properties or more requests a month, choose one of our pricing plans.

Client-side and server-side

Whether it's a web page in a browser or a Node.js app on your server, install it with:

$ npm i @51degrees/ua-parser-js --save

Detect Apple devices

Unlike some other User-Agent parsers, UAParser can tell iPhone and iPad models apart with a paid plan. See what to expect from Apple model detection.

A human touch

Our team of data analysts keeps the device data up to date.

Getting started

Follow the steps in the README on GitHub to add UAParser to your project.

UAParser needs a Resource Key. Create one from this link, which opens with the main device properties ticked. Some of them need a paid plan.

To choose your own properties, see our guide to Resource Keys. For reliable Apple detection, include the JavascriptHardwareProfile property.

Want to see it in action? Watch our webinar.

The recommended properties for your Resource Key are:
  • IsMobile
  • HardwareVendor, HardwareModel, HardwareName
  • PlatformVendor, PlatformName, PlatformVersion
  • LayoutEngine
  • BrowserVendor, BrowserName, BrowserVersion
  • JavascriptHardwareProfile
  • DeviceType
  • SetHeaderBrowserAccept-CH,
    SetHeaderHardwareAccept-CH,
    SetHeaderPlatformAccept-CH,
